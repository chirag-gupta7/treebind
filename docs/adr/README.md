# Architecture decision records

A question that shapes the API, the architecture or the security model is
raised as a `kind/decision` issue and ends in a short record here. Records are
numbered in the order they are accepted and are not rewritten afterwards: a
later decision that changes an earlier one gets its own record and says which it
supersedes.

## Template

Copy this into `NNNN-short-title.md`.

```markdown
# NNNN. Short title

- Status: proposed | accepted | superseded by NNNN
- Date: YYYY-MM-DD
- Issue: #<number>

## Context

What is the situation, and what forces are at play?

## Decision

What did we decide, in one or two sentences?

## Consequences

What becomes easier or harder, and what do we need to watch?
```
